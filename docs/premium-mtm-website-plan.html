১. প্রকল্পের লক্ষ্য

বাংলাদেশে তৈরি premium made-to-measure suit, shirt, trouser ও women’s dress US/EU গ্রাহকের কাছে বিক্রির জন্য একটি আধুনিক D2C platform। সাইটটি luxury craftsmanship, personalized fitting, secure payment, আন্তর্জাতিক delivery এবং premium after-sales support তুলে ধরবে।

মূল business flow: Product নির্বাচন → customization → measurement → checkout → measurement review → tailoring/quality control → shipment → alteration support।

৪. User roles ও permission

Roles: Customer, Admin, SuperAdmin, Tailor, OrderManager, ContentManager ও SupportAgent। শুধু role check নয়, granular permission ব্যবহার করতে হবে: products.manage, orders.manage, measurements.review, payments.view, refunds.manage, content.manage, reports.view, users.manage এবং settings.manage।

৫. Authorization model

  • Default/fallback policy: authenticated user আবশ্যক।
  • Homepage, catalog ও product detail-এর read-only endpoint public থাকবে; rate limiting এবং caching থাকবে।
  • Cart, wishlist, measurements, checkout, orders ও account endpoint Customer authorization চাইবে।
  • Admin endpoint role + permission policy দিয়ে সুরক্ষিত হবে।
  • Payment/shipping webhook JWT ব্যবহার করবে না; provider signature এবং idempotency যাচাই করবে।
কেন কিছু public endpoint দরকার: সব endpoint login-required হলে নতুন visitor product বা homepage দেখতে পারবে না। তাই public read-only endpoint ছাড়া সব API secured রাখা হবে।

৬. Customer website modules

Storefront ও content

  • Luxury homepage, Men/Women collections, category, search, filters ও sorting
  • Product details, fabric provenance, craftsmanship, delivery estimate এবং related products
  • How It Works, Craftsmanship, Fabric Story, Lookbook/Journal, FAQ ও policy pages

Product customization

Fabric, color/pattern, fit, jacket/lapel/button/vent/lining, trouser style, shirt collar/cuff, dress neckline/sleeve/length, monogram, personal notes, rush production ও luxury packaging। প্রতিটি option price modifier সমর্থন করবে এবং order-এর সঙ্গে immutable snapshot থাকবে।

Measurement system

  • Guided manual measurement wizard, inches/cm, instructional media ও expected-range validation
  • Self-measure, local tailor এবং virtual fitting—তিনটি পথ
  • Front/side photos, fit preference, saved profiles, version history
  • Admin/tailor approval ও correction request workflow
  • পরবর্তী release-এ common provider interface-এর মাধ্যমে AI sizing integration

Customer account

Profile, addresses, measurement profiles, wishlist, cart, checkout, order history, production timeline, tracking, invoice, virtual consultation, support conversation, alteration-credit claim ও review।

৭. Order ও production workflow

Cart → Checkout → Payment → Measurement Submitted → Measurement Review
→ Fabric Allocated → Pattern → Cutting → Tailoring → First QC
→ Finishing → Final QC → Premium Packaging → Shipped → Delivered
→ Alteration Support / Completed

প্রতিটি stage-এ customer-visible status, internal status, timestamp, responsible staff, optional photo, staff note ও notification থাকবে।

১২. Security checklist

  • Short-lived access token, rotating refresh token ও HttpOnly/Secure cookie
  • Email verification, strong password, lockout, rate limiting এবং admin 2FA
  • CORS allow-list, HTTPS, security headers, DTO validation ও safe error responses
  • Upload-এর MIME/signature/size validation; private storage এবং signed URL
  • Payment card data database-এ নয়; provider-hosted/tokenized payment flow
  • Webhook signature, idempotency key ও duplicate-event protection
  • Audit logs, encrypted secrets, sensitive-data-safe logging
  • Automated backup, restore test, dependency/security scan

১৩. Development phases

Phase 1 — Foundation: requirements, repository, API/UI projects, Docker, PostgreSQL, authentication, permissions, logging, error handling ও CI.
Phase 2 — Catalog & CMS: categories, products, fabrics, customizations, collections, media, storefront, SEO ও CMS.
Phase 3 — Measurements: guided wizard, profiles, photos, validation, admin review, correction ও virtual fitting.
Phase 4 — Commerce: cart, coupons, address, price calculation, payment abstraction, checkout, orders, email ও invoice.
Phase 5 — Production & Delivery: production stages, assignments, QC, packaging, shipment, tracking ও notifications.
Phase 6 — Premium Support: alteration claims, support tickets, reviews, wishlist ও consultation calendar.
Phase 7 — Hardening: analytics, reports, accessibility, performance, security এবং automated tests.
Phase 8 — Launch: production infrastructure, domain/SSL, live integrations, monitoring, backups, UAT ও release.
MVP: Phase 1–5। AI sizing, advanced recommendation, loyalty এবং sophisticated multi-currency settlement পরবর্তী release-এ রাখা যাবে।
